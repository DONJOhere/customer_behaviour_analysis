Customer Shopping Behavior Analysis

Python | SQL | Power BI | Data Analytics

This project focuses on analyzing customer shopping behavior and finding useful business insights from customer transaction data.

I worked on the project as an end-to-end analytics workflow, starting with data cleaning and exploratory analysis in Python, followed by SQL-based analysis and an interactive Power BI dashboard.

The main goal was to understand customer purchasing patterns, product performance, customer preferences, and other factors that can help a business make better decisions.


**Project Overview**

The project covers the complete data analytics process:

• Loading and understanding the raw dataset
• Cleaning and preparing the data using Python
• Performing exploratory data analysis
• Writing SQL queries to answer business questions
• Creating an interactive Power BI dashboard
• Identifying important business insights
• Preparing a project report and presentation


**Dataset**

The dataset contains customer shopping information such as:

• Customer demographics
• Age and gender
• Products purchased
• Product categories
• Purchase amount
• Review ratings
• Subscription status
• Discount usage
• Shipping preferences
• Purchase frequency
• Previous purchases

**Python – Data Cleaning & EDA**

The initial analysis was performed using Python and Pandas.

The main steps included:

• Understanding the structure of the dataset
• Checking data types
• Identifying missing values
• Checking duplicate records
• Cleaning inconsistent values
• Converting columns to appropriate data types
• Creating additional columns where required
• Exploring relationships and patterns in the data

Libraries such as Matplotlib and Seaborn were used to visualize the data and identify trends.


**SQL Analysis**

After preparing the data, I used SQL to perform business-oriented analysis.

Some of the questions explored were:

• Which products are purchased most frequently?
• Which categories have higher average purchase amounts?
• What are the average product ratings?
• How does purchasing behavior differ across customer groups?
• How does subscription status relate to customer behavior?
• How frequently do customers make purchases?
• How are discounts being used?
• Which products or categories show stronger customer engagement?

SQL concepts used in the project include:

• SELECT
• WHERE
• GROUP BY
• HAVING
• ORDER BY
• CASE
• Aggregate functions
• JOINs
• Subqueries
• CTEs
• Window functions
